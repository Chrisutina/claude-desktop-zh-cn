# Windows 官方订阅账号本地化

源码修复版 **1.4.11**（2026-10-03），资源核对客户端为 **Claude Desktop 2.19675.0**。下载 [main 分支源码 ZIP](https://github.com/Chrisutina/claude-desktop-zh-cn/archive/refs/heads/main.zip)；源码版本与客户端版本分别记录。

运行 `install-windows.bat`，选择 **2：官方账号登录模式（完整汉化）→ 1：简体中文**。不需要第三方 API 配置。重新安装会关闭并重启 Claude，先结束正在运行的任务。

## 本轮修复

- 保留 `Low / Medium / High / Extra / Max` 和 `Effort` 原名，翻译说明文字；其他场景共用的低、中、高键仍保留中文。
- 补齐常规、Code、系统、Chrome 扩展与网站权限、订阅用量和余额等文案。
- 新增模型动态词库。目标版本的新键回退英文，五个思考等级保持英文。
- 补齐右键菜单的检查元素、复制链接/图片、词典和默认浏览器标签；拼写建议本身保持原文。
- 在线词表区分大小写，避免 `Extensions` 被 `EXTENSIONS` 覆盖。
- 支持百分比、优惠上限、星期和 12/24 小时重置时间、到期日及倒计时。
- 最后注入在线词表，避免模型文案替换改坏英文匹配键。
- 跟踪语言文件是否为本次新建，卸载时保留安装前已经存在的文件。

显示层翻译不会设置网站权限、开启付费余额、购买额度或重置用量。代码、用户消息和输入内容受保护。

## 验证范围

已核对英文源、ICU 变量与分支、富文本标签，以及 Windows PowerShell 实际生成脚本。回归覆盖动态文案、大小写区分、英文思考等级和用户内容保护；只在临时目录中测试文件跟踪、合并和卸载。

客户端和在线页面会持续更新，词条数量不代表所有页面已经汉化。新增文案可能继续回退英文。安装后请检查实际使用的模型选项、右键菜单和设置页；发现漏翻时提供页面位置、英文原文及隐去账号信息的截图。

此次更新集中在 Windows 简体中文，macOS 安装脚本和其他语言词库保持原有实现。旧截图仅供参考。
